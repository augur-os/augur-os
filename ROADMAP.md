# Roadmap

This roadmap covers the open-source Augur runtime for **PC & Mac** (MIT-licensed). Team,
edge, and shared-org-brain deployment is **Augur Enterprise** — a separate, closed-source
product on its own track. Contact us for edge and enterprise deployment.

**Open source: soft launch (live).** The architecture and the PC & Mac runtime are public
now under an MIT license — installable today via the [Quick Start](README.md#quick-start).
This is a soft launch, not a 1.0: macOS is supported, Windows validation is in progress, and
the core is still hardening, so expect rough edges. We'd rather ship it right than ship it dated.

## Now

Stabilizing the soft launch so a first install just works.

- **Soft launch (live):** the architecture and the PC & Mac runtime are public and installable.
- **Hardening the core:** clone-and-compose, the compounding engine, and the control layer.
- **Reliable first run:** smoother onboarding (plugins, builder mode, top features) and self-recovery when something breaks.
- **Polishing the surfaces you touch first:** Browse, Workspace, skills & plugin management, and ask/chat — plus dashboard load performance.
- **A focused, personal-OS-first** set of skills and plugins, with example skills and a guided first run.
- **Verified clean-environment install across OSes** as a release gate: macOS supported, Windows validation in progress.

## Next

Graduate from soft launch to a broadly public-ready release.

- Graduate to a broadly public-ready release once the core is stable, on a predictable release cadence.
- Complete Windows validation and fold it into the public support story.
- **Capture & inbox workflow:** triage free notes, unify inboxes, and map local files into your brain.
- **Richer in-chat tooling:** commands with examples, screenshots as context, notes as a chat surface.
- **"Everyone's a builder":** smoother skill authoring (skillify, standardization, auto-discovery) and community skill sharing.
- **Integrations:** editor/agent integrations (Codex, Copilot, GitHub) and cloud backup/snapshots.

## Later

- **Advanced capabilities:** typed/graph retrieval with selective forget, computer control, richer automation, and stand-alone export of skills and dashboards.
- **Augur Enterprise (separate, closed-source track):** team, edge-fleet, and shared-org-brain deployment (robots, kiosks, on-prem nodes), org analytics, scheduled tasks, and a skill marketplace. Contact us for edge and enterprise deployment.
