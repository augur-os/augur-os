# Roadmap

This roadmap covers the open-source Augur runtime for **PC & Mac** (MIT-licensed). Team,
edge, and shared-org-brain deployment is **Augur Enterprise** — a separate, closed-source
product on its own track. Contact us for edge and enterprise deployment.

**Open source: soft launch (live).** The architecture and the PC & Mac runtime are public
now under an MIT license — installable today via the [Quick Start](README.md#quick-start).
This is a soft launch, not a 1.0: macOS is supported, Windows validation is in progress, and
the core is still hardening, so expect rough edges. We'd rather ship it right than ship it dated.

## Now

- Soft launch: the architecture and the PC & Mac runtime are public and installable.
- macOS support is implemented; Windows architecture is implemented, validation in progress.
- Hardening the core: clone-and-compose, the compounding engine, and the control layer.

## Next

- Graduate from soft launch to a broadly public-ready release once the core is stable.
- Begin a predictable release cadence and complete Windows validation.

## Later

- Fold validated Windows support into the public support story.
- Team and edge-fleet deployment (robots, kiosks, on-prem nodes) ships via Augur Enterprise.
