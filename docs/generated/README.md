# Generated Indexes

Auto-generated reference artifacts. Regenerated by CI/nightly — **never hand-edit these files**.
Tracked JSON files are the source of truth for code, dashboard, and Browse consumers. Generated
Markdown reports under `docs/generated/*.md` are local/nightly convenience output unless explicitly
unignored in `.gitignore`.

## Contents
- `adr-index.md` — All ADRs with status summaries
- `coverage-gaps-report.md` — Auto-loop evolution gaps
- `flow-optimizer-report.md` — Flow optimization recommendations
- `orphan-plans-report.md` — Orphan design plan audit
- `route-map.md` — All dashboard routes mapped to source files
- `skill-classification-report.md` — Skill classification by hub/type
- `skill-manifest.json` — Full tracked skill metadata for active shared/private inventory
- `skill-release-matrix.json` — Release staging matrix and cumulative target summaries
- `tech-debt-report.md` — TODO_ marker scan results
- `hardening/` — Hardening reports (auto-rotated, kept 14 days)

## Regeneration
```bash
python3 .github/scripts/generate_adr_index.py
python3 .github/scripts/generate_route_map.py
python3 scripts/generate-skill-release-matrix.py
```

Optional local Markdown convenience views:

```bash
python3 .github/scripts/generate_skill_registry.py
```
