## Bug Log

_(populated during real-user testing; newest first)_

### B1 — Fresh/un-onboarded vault → hard 500 on `/api/session/init` and `/api/cli/configs` (S2, robustness)
- **Repro:** Point dashboard at a vault without `_augur/config/ai/cli_agents.yaml` (e.g. brand-new brain), load `/browse`.
- **Expected:** Graceful default (empty agent list / no CLI agents), page still functional.
- **Actual:** Both endpoints return HTTP 500 with `cli_agents.yaml not found at any candidate path: ...`; console shows 2 errors on every page load. Session init fails.
- **Evidence:** `curl /api/cli/configs` → 500 `{"error":"cli_agents.yaml not found..."}`; same for POST `/api/session/init`.
- **Root cause:** `apps/dashboard/app/api/cli/cli-config.ts:142` throws when no candidate path exists; no repo default/template seeds the file; candidate list also has a duplicate (`AUGUR_VAULT_CONFIG_DIR/ai` == `AUGUR_VAULT_DIR/_augur/config/ai`).
- **Status:** Unblocked testing by seeding non-personal `cli_agents.yaml`. Robustness fix (graceful fallback + dedup candidates) deferred to fix phase.

### B2 — Memory/daily-logs subsystem is runtime-scoped, not vault-scoped (isolation/architecture finding, S3)
- **Observation:** With `AUGUR_VAULT` pointed at a synthetic vault, the Memory page still shows real decisions ("native Windows support execution 2026-04-13", "44 decisions") and real memory slugs (`dev-merge-paths-collateral`). `knowledge-memory-profile` correctly reads the synthetic (empty) vault, but `memory-search` returns real data.
- **Root cause:** `src/lib/knowledge/search.py:72` & `curator.py:56` set `_daily_dir = get_runtime_dir()/memory/daily` — daily logs are keyed to runtime, not vault. `get_memory_dir()` (MEMORY.md write target) DOES honor `AUGUR_VAULT`, so curation *writes* land in the synthetic vault, but *reads* pull real daily logs.
- **Impact:** A "synthetic vault" does not fully isolate the memory surface; full isolation also needs `AUGUR_STATE`, which collides with dev-server instance management (runtime_dir keys the dev instance registry). Documented design tension worth an ADR note.
- **QA safety decision:** Mutating memory workflows (Curate Memory, memory-review approve/reject) are NOT exercised in this run — write target not confirmed fully isolated. Tested read/render + modal-open only. Flagged for explicit confirmation before mutation testing.

- **File:** `apps/dashboard/app/api/cli/cli-config.ts`

- **Regression test:** `tests/dashboard/api/cli-config.test.ts` → new case "degrades to the default agent without throwing when cli_agents.yaml is absent (B1)". Suite: **14/14 pass**.
