Augur full-system refactor to "categorize around skills." Design spec (brainstorming output,
2026-06-09) at `docs/superpowers/specs/2026-06-09-augur-category-action-refactor-design.md`,
committed on branch `design/category-action-refactor`.

**Goal:** collapse ~23 Browse categories → ~7 user-facing + 3 developer groups, with a Skill as
the unit. Skill-owned artifacts (Actions, Workflows, Pages, Extensions) stop being top-level tabs.

**Flagship = Actions workstream (locked decisions):**
- DELETE the dead `augur/actions/*.md` pipeline (59 files, 58 empty `*-overview` stubs) + `index_actions()` + Browse "Actions" tab + orphaned WebMCP `actions.*` + `execute-fast-action`/missing `config/action_buttons.yaml`. Needs a superseding ADR over 130/143/162/263. Verified: nothing user-facing breaks.
- UNIFY to one `{skill}/augur/actions.yaml` sidecar (fields: id,label,kind[ai|mcp],mcp_tool/template,dispatch[fire|oneshot|ide|modal],surfaces[card,page,html]). Feeds the existing card baker (`generate-item-actions.ts`) AND the runtime dispatcher (`useActionRunner.ts`). `browse-actions.yaml`(18 live) + `SKILL.md contributions.actions[]`(2 live) migrate in.
- BRIDGE sandboxed Pages HTML → AI via origin-checked `postMessage` exposing only `augur.ask(prompt)` (human-confirmed) + `augur.runAction(id)` for the page's owning-skill declared actions. No arbitrary MCP from HTML.

**Key finding:** "action" was 5 half-wired representations; only `browse-actions.yaml` + `SKILL.md contributions.actions` were live; `augur/actions/*.md` is dead (card buttons ignore the file body). User-authored HTML-button→AI flow did NOT exist (sandboxed iframe, no bridge) — Part 3 builds it.

**Workstream roadmap:** 1) Actions (first) · 2) Skills-as-heart (dedupe autosync client duplicates that inflate the 179 count; fold Workflows as own SKILL.md per ADR-805; delete Extensions) · 3) Content cleanup (Profile→tagged note, Sources→Documents detail, Drafts→CLI-only, Documents `SKILL.md`/media leak, Pages `/unknown` route fix) · 4) Integrations→teachable CLI capability registry · 5) Dev-tier collapse + fix `scripts` & `ai-artifact-inventory` scanners.
