# Advisor Architecture And Product Review System

## Compiled truth

### Current Thesis

Advisor is the read-only review layer for architecture, backend patterns, product vision, refactor planning, scaffolding, structure validation, and alignment scoring.

### What This Page Knows

The advisor skill sets the boundary: it analyzes, scores, and recommends while execution agents edit code. Architecture and backend modules provide the vocabulary for entry points, traces, layers, schemas, APIs, and data models. Product vision, refactor, scaffold, structure, and alignment sources turn review into implementation-ready recommendations without crossing the read-only line.

### Key Dimensions

- Advisor can inspect and score but should not mutate application code.
- Architecture review starts with entry points, boundaries, traces, and layers.
- Backend review covers APIs, schemas, persistence, services, security, and performance.
- Refactor and scaffold guidance adapt or create skills within Augur structure.
- Vision and alignment scoring protect the roadmap from plausible but low-fit work.

### Recent Shifts

- Recovered modules broaden advisor beyond prompt optimization.

### Open Tensions

- Read-only advice needs clear handoff into implementation work.

### How to Use This

Use this when asking advisor to inspect architecture, evaluate a proposal, adapt a repository, validate skill structure, or check product fit.

### Open Questions

- Which advisor findings should automatically become backlog items?
