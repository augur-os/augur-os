# Advisor Operating Guides And Workflow Patterns

## Compiled truth

### Current Thesis

Advisor operating guides define how analysis, architecture, prompt optimization, drift control, integration review, and system optimization should move from evidence to recommendations.

### What This Page Knows

The reference sources collect analyst workflows, metrics patterns, architect workflows, blueprint templates, drift detection, cross-skill integration patterns, horizontal and vertical architecture, prompt optimization, vision structure, and multi-step advisor workflows. The ops-refactor workflow adds a live audit route for checking agent capabilities and cross-agent parity. Together they turn advisor from a loose review role into an operating manual for when to analyze, design, refactor, validate, and migrate workflows.

### Key Dimensions

- Analyst guides cover usage logs, prompt variants, A/B tests, telemetry dashboards, token analysis, and recommendations.
- Architect guides cover discovery, match scoring, requirements analysis, pattern selection, data modeling, and decisive blueprints.
- Drift and vision references keep technical work aligned with strategic pillars and resource focus.
- Integration references define shared storage, read/write contracts, file locks, and cross-skill boundaries.
- Ops refactor audits latest agent capabilities and portability across Claude Code, Cursor, Windsurf, Gemini CLI, and related clients.
- System optimization workflows sequence analysis, collateral cleanup, git optimization, design, implementation, and verification.

### Recent Shifts

- Advisor reference material now compiles into one operating guide concept rather than scattered module notes.
- Capability migration and cross-agent parity are part of the advisor workflow surface.

### Open Tensions

- Advisor should recommend migrations without bypassing implementation and verification ownership.
- Reference guides can become stale unless they are tied to telemetry, current agent capabilities, and verified actions.

### How to Use This

Use this when advisor needs to choose the right review mode: usage analysis, prompt optimization, architecture design, drift review, integration design, system optimization, or capability migration.

### Open Questions

- How often should ops-refactor refresh cross-agent parity assumptions?
- Which advisor guide should become the default entrypoint for system optimization?
