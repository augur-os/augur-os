# Advisor Data

Advisory skill data — analytics, design artifacts, and evaluation outputs.

## Structure
- `analytics/` — Analyst data: prompts, telemetry, eval harness, complexity reports
  - `analytics/telemetry.yaml` — Imported runtime telemetry snapshot
  - `analytics/backlog.yaml` — Imported executor backlog snapshot
- `design/` — Architect data: vision configs, retrospectives, specs, productization plans
