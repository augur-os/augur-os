# Agent Learning Compounding Pipeline

## Compiled truth

### Current Thesis

Agent learning compounds when memory, RAG, relationship metadata, and wiki batches preserve reusable structure for future agents.

### What This Page Knows

Existing sources connect memory persistence, RAG indexing, source freshness, and concept-first wiki compilation. The RAG knowledge graph plan adds relationship indexes between skills, collections, chains, external folders, and high-value documents. The durable idea is a human-readable relationship layer that improves retrieval without replacing the vault or compiled wiki. The knowledge skill shows why retrieval cannot be treated as one flat index: memory, documents, and project knowledge each have their own storage and freshness failure modes. Durable learning comes from preserving those boundaries while exposing a unified search surface. The learning and vault sources connect daily logs, document freshness, agent synchronization, memory sync, RAG updates, project indexing, and advisor design material. They point toward one compounding mechanism: agents preserve useful session outcomes, maintenance loops keep source indexes current, and wiki compilation waits for enough related evidence before publishing durable pages. This prevents the wiki from becoming a thin index while still allowing conversations to improve future answers. This source strengthens agent learning compounding pipeline by adding reusable detail that belongs in the compiled wiki.

### Recent Shifts

- Advisor and workflow vault material is being treated as evidence for operating patterns, not only as stored project collateral.
- Relationship-aware RAG adds graph-style retrieval without a heavy opaque dependency.
- Session-end hooks and instructions are becoming the harness that ensures agents remember to save synthesis and request wiki updates.
- The skill frames stale project indexes as an operational gotcha rather than a user error.
- The wiki compiler now treats few-source pages as draft or pending cluster material instead of writing every extracted idea immediately.
- This batch adds new evidence that sharpens the existing wiki concept.

### Open Tensions

- Agent instructions can ask for compounding at session end, but hooks must provide a safety net when interactive work stops abruptly.
- More relationship detail helps routing but can flood context if loaded by default.
- The concept should stay evidence-backed and avoid drifting into catch-all synthesis.
- The pipeline needs enough editorial friction to prevent index pages while still keeping up with real user work.
- Too much automatic capture creates noisy source cards; too little capture means the wiki cannot learn from useful conversations.
- Unified search is useful, but it can hide which backend is stale or empty unless diagnostics stay explicit.
