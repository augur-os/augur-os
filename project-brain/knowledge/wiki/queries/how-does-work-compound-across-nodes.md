# How does work compound across nodes?

Work compounds because every ingest event is extracted into durable concept pages via
[[the-wiki-compounding-engine]] — a four-phase pipeline (source inventory → state
reconciliation → batch extraction → concept compilation) that enriches the wiki on
every dream cycle. At fleet scale [[one-brain-above-the-fleet]] carries the same
compiled knowledge down to every edge node, so each branch inherits accumulated
observations from the entire fleet rather than starting cold. The compounding is
structural: the brain, not the agent, retains and appreciates the work.
