# How should Adaptive loop maintenance surfaces be used?

## Summary

A reusable answer for applying [[concepts/adaptive-loop-maintenance-surfaces]].

## Answer

Adaptive loop maintenance surfaces are the skill pages and action overviews that expose documentation quality, hub coverage, memory, observability, ops, repo hygiene, and markdown/frontmatter loops. The concept matters because Augur’s maintenance system is decentralized across loop-owned skills but needs a coherent operational map.

Use [[concepts/adaptive-loop-maintenance-surfaces]] as the source-backed synthesis page before returning to raw evidence.
