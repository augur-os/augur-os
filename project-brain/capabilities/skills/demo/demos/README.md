# Ingest Workflow Example Runbooks

This directory contains live workflow example scripts for the ingest skill.

Rules:

- Every workflow example file starts with `demo_`.
- Every workflow example file is a frontmatter-backed markdown card.
- Every workflow example file is intended to be pinned in Browse.
- Workflow example scripts use real Augur commands and real source cards.
- Workflow Example 3 must first capture the audio file with `/keep` and then use the returned Augur-owned path.
