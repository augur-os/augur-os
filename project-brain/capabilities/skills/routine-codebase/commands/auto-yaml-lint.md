# auto-yaml-lint

Lint YAML configuration files for syntax errors, formatting drift, duplicate keys, and deep nesting.

## Scan

Validates `config/` and skill-owned YAML for syntax and structure issues.

## Fix

Applies safe hygiene fixes and reports duplicate-key or deep-nesting violations for follow-up.
