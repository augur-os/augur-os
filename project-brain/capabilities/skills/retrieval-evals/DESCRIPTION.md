# Retrieval Evals

Portable file-first retrieval evaluation workflows for defining JSONL query
datasets, recording judgments, replaying local retrieval outputs, calculating
metrics, and writing reports. The standard core focuses on reusable eval
formats and deterministic scoring that can run without a platform runtime.

Platform-specific capture surfaces, retrieval-stack integration, dashboard
pages, runtime report locations, and generated-client behavior belong in an
adapter outside this standard source.
