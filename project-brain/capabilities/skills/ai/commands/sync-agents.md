# sync-agents

Detect drift between source agent rules and generated IDE configs (CLAUDE.md,
.cursorrules, .windsurfrules, etc.), then regenerate when stale.
Daemon-managed (knowledge-enrichment loop, tier 1).

## Scan

Runs `PYTHONPATH=project-brain/capabilities python -m skills.ai.scripts.sync_agents check` to compare source rules against generated output.
Returns an issue when any generated config is out of date.

## Fix

Runs `PYTHONPATH=project-brain/capabilities python -m skills.ai.scripts.sync_agents sync all` to regenerate all IDE configs, stages only known
generated files, and commits. Scoped staging prevents sweeping unrelated changes.

In worktrees, repo-local client exports are local bootstrap artifacts regenerated by worktree bootstrap and
should not be committed unless they are part of the intentionally versioned tracked-generated set.

Use `--purge` for Augur-managed artifacts only.
Use `--purge-state` for supported client state reset while preserving settings/config.
