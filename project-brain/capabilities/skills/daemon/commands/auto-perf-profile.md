# auto-perf-profile

Check response times, disk bloat, stale files, cache size, and flag IO/performance regressions. Daemon-managed (nightly loop, tier 1).

## Scan

Profiles system performance metrics including disk usage, cache sizes, stale file counts, and response times.

## Fix

Cleans up stale files, trims bloated caches, and reports performance regressions.
