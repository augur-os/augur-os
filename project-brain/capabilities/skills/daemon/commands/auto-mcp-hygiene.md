# auto-mcp-hygiene

Per-plugin MCP tool naming, registration, dead-tool, and duplicate audit. Daemon-managed (nightly loop, tier 1).

## Scan

Audits MCP tool registrations across all plugins for naming violations, dead tools, and duplicate registrations.

## Fix

Reports violations and removes dead tool registrations.
