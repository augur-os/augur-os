# Local Audio Processing

Portable local audio workflows for discovering recordings, preparing
transcription, checking transcript quality, and classifying audio context from
user-provided files. The standard core stays file-first and local-first, with
agent judgment handled by the active AI client.

Platform-specific ingest lanes, source-card writes, MCP result submission,
runtime queues, dashboard pages, and generated-client behavior belong in an
adapter outside this standard source.
