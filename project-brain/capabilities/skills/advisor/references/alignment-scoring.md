# Alignment Scoring

## Alignment Scale
| Score | Label | Description |
|-------|-------|-------------|
| 5 | Strong Alignment | Directly advances core mission |
| 4 | Good Alignment | Supports strategic pillars |
| 3 | Neutral | Neither advances nor detracts |
| 2 | Weak Alignment | Tangential to mission |
| 1 | Misaligned | Potentially harmful to vision |

## Assessment Template
```markdown
## Vision Check: [Initiative Name]

### Initiative Summary
[What is being proposed]

### Alignment Analysis
| Dimension | Score | Notes |
|-----------|-------|-------|
| Mission fit | X/5 | [Comment] |
| Strategic pillar | X/5 | [Which pillar?] |
| Value alignment | X/5 | [Comment] |
| Goal contribution | X/5 | [Which goal?] |

### Overall Score: X.X/5

### Verdict
- [ ] Strong Alignment - Proceed
- [ ] Partial Alignment - Refine
- [ ] Misaligned - Reconsider

### Recommendations
1. [How to improve alignment]
2. [Concerns to address]
```
