# Drift Detection

## Drift Indicators
| Signal | Description | Severity |
|--------|-------------|----------|
| Scope creep | Features unrelated to core | Medium |
| Shiny object | Chasing trends | Medium |
| Customer pressure | Building for one customer | High |
| Competitive reaction | Copying competitors | High |
| Resource drift | Talent on non-core work | High |
