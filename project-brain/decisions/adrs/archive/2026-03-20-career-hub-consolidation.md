# Career Hub Consolidation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate 28 career hub pages into 6 focused tabs, eliminating nav-only pages, duplicates, and AI fluff.

**Architecture:** Source pages live in `plugins/ui/pages/career/`. After editing, run `npm run mount-plugins` to sync to `apps/dashboard/app/career/`, then regenerate the tab registry. Each new tab page is a single file that imports existing sub-components from their current locations (moved alongside the page).

**Tech Stack:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS, glass-panel design system

## Important Context

- **Source vs mounted:** NEVER edit files in `apps/dashboard/app/career/` -- those are auto-generated copies. Edit only in `plugins/ui/pages/career/`.
- **Mount command:** `cd apps/dashboard && npx tsx scripts/mount-plugins.ts` copies source pages to the app directory.
- **Tab registry:** Generated by `apps/dashboard/scripts/generate-tab-registry.ts`. After restructuring routes, regenerate: `cd apps/dashboard && npx tsx scripts/generate-tab-registry.ts`
- **Build verify:** `cd apps/dashboard && npm run build` -- must pass with zero errors.
- **API routes stay unchanged:** All `/api/career/career/*` routes remain. Pages just import from them at new paths.
- **Design patterns:** Use `glass-panel`, `GlassCard`, CSS variables (`var(--text-primary)`, etc.), `useCachedFetch`, `useActionRunner`.
- **Fluff to remove:** Any component that is purely static text (StarFrameworkGuide, ResumeTipsCard), generic "AI can help" cards (AIInterviewPrepCard, ResumeAIToolsCard), navigation-only sections (CareerNavSection, GrowthNavSection), and "Cross-Hub Links" footers.
- **Known gap:** `/api/career/career/guard` may not exist yet -- the Guard section will show empty data (pre-existing state, out of scope for this consolidation).
- **Intentional deletions:** `career-subpages.ts` (navigation config consumed only by the nav-only page being deleted). `ProfileCvsPanel.tsx`/`ProfileDocPanel.tsx` are moved to pipeline/ since CareerTable imports from `./actions` which references them.
