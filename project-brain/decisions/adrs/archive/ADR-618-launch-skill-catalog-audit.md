# ADR-618: Launch Skill Catalog Audit

## Decision summary

Adopt a per-skill **launch audit** as the primary method, gated by the lens "would a new user get meaningful value from this skill in one session?". Apply a strict **fresh-install standard**: skills must work out of the box, or have a clean onboarding/connect path that counts as normal setup. Score...
