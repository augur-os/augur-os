# Wiki Report Design — Second Brain Intelligence Report

**Date:** 2026-04-11
**Status:** Draft
**Depends on:** Phase 2 LLM Wiki (merged)

## Summary

`/wiki report` generates a polished "Second Brain Intelligence Report" — a shareable PDF + HTML artifact that reads like a personal analyst briefing, not a dashboard. The AI reads all wiki pages, extracts human-style insights about the user (who they are, what they know, how they think, what's missing), renders charts and a knowledge graph, and produces a document designed to be screenshotted and shared.

This is the viral demo artifact for Augur: "I dropped 1,035 files. My AI read them all and wrote this about me."

## Command

```
/wiki report [--style demo|editorial|minimal] [--hub <hub>] [--output <path>]
```

- Default style: `demo` (dark mode, data-rich, shareable)
- `--hub` scopes to one domain
- `--output` overrides default output path
- Generates both PDF and HTML

Default output: `{vault}/reports/second-brain-report-YYYY-MM-DD.pdf` + `.html`

## Report Structure (4 pages)

### Page 1: Cover

- Title: "What Your AI Knows About You"
- Branded gradient header with Augur mark
- Profile photo from portfolio folder (if available)
- **One-paragraph synthesis** — the AI writes a 2-3 sentence personal summary based on ALL wiki content. This is the viral hook — it reads like someone who knows you.
- Stat bar: pages, domains, sources ingested, words synthesized, cross-references
- Footer: "Generated by Augur — your second brain, on your machine — augur.run"

### Page 2: Who You Are

- **What You Do** — narrative paragraph synthesized from wiki content about the user's work, projects, responsibilities
- **How You Think** — decision patterns, preferences, and values extracted from ADRs, memory, and behavioral data
- **Expertise Stack** — ranked domain expertise with human labels (Expert/Advanced/Active/Growing), rendered as horizontal bars. Derived from source depth + page density + cross-reference count per domain.
- Portfolio images contextually placed if available (project screenshots next to expertise bars)

### Page 3: What Your Brain Contains

Per-hub paragraphs — not page listings, but **actual knowledge summaries**:
- Each hub gets a colored card with source count and a narrative paragraph
- The paragraph synthesizes what the wiki pages in that hub actually say
- Example: "Actively job searching with 6 CV variants tailored for different roles. Salary expectations calibrated for Israeli tech market 2024-2025."
- Hub icons (emoji or lucide) for visual identity

### Page 4: Patterns & Blind Spots

Split into two columns:

**Patterns Your AI Noticed:**
- Cross-domain connections (e.g., "career prep is engineer-grade — 23 cross-refs between dev and interview prep")
- Behavioral patterns (e.g., "you build systems, not features")
- Values (e.g., "local-first is a conviction, not a constraint")

**Blind Spots & Gaps:**
- Thin domains (e.g., "financial brain is almost empty — 9 sources")
- Reactive patterns (e.g., "health tracks problems, not wellness")
- Work:life ratio observation
- Specific recommendations ("consider ingesting budget data, investment reports")

## Generated Visualizations

All rendered as PNG images and embedded in both PDF and HTML.

### Knowledge Radar Chart
- Spider/radar chart showing depth per domain
- 6-8 axes (top domains by source count)
- Rendered via matplotlib
- Shows strengths and gaps at a glance

### Knowledge Graph
- Force-directed node graph of wiki pages connected by `[[wikilinks]]`
- Nodes colored by hub, sized by cross-reference count
- Rendered via networkx + matplotlib
- Shows how knowledge domains interconnect

### Hub Distribution Bar
- Horizontal stacked bar showing source distribution across hubs
- Color-coded by hub
- Rendered via matplotlib

## Portfolio Folder

`{vault}/portfolio/` — user drops images here, the report generator uses them contextually:

| File pattern | Placement |
|-------------|-----------|
| `profile.*` (jpg/png) | Cover page, next to name |
| `logo.*` | Footer, next to "Augur" branding |
| `{hub}-*.*` (e.g., `dev-dashboard.png`) | Hub section as inline image |
| `cover.*` | Cover page background |

The generator scans the folder, matches by filename pattern, and places images. Missing images are gracefully skipped — the report works without any portfolio assets.

## Technical Architecture

### Execution Model

Per `docs/references/ai-client-execution-model.md`: the agent orchestrates the report generation. MCP tools are stateless hands.

**Flow:**
1. Agent receives `/wiki report` command
2. Calls `wiki-list` to get all pages
3. Calls `wiki-tags` for the manifest
4. Calls `wiki-read` for each page (or batch)
5. Agent synthesizes insights from page content using LLM capability
6. Calls `wiki-report-generate` MCP tool with structured report data
7. MCP tool renders PDF + HTML using ReportLab + Jinja2
8. Returns file paths

### MCP Tools (new)

| Tool | Type | Args | Returns |
|------|------|------|---------|
| `wiki-report-generate` | mutation | `{report_data, style, output_dir}` | `{pdf_path, html_path}` |
| `wiki-report-data` | read | `{hub?}` | `{stats, pages, tags, connections}` — raw data for report |

`wiki-report-generate` is a mechanical renderer — it takes structured JSON (sections, insights, stats, image paths) and produces PDF + HTML. The agent does all the thinking (writing insights, extracting patterns, identifying blind spots).

`wiki-report-data` is a convenience tool that aggregates wiki stats, page metadata, and cross-reference counts — saves the agent from making 50+ individual wiki-read calls.

### Rendering Stack

| Format | Library | Purpose |
|--------|---------|---------|
| PDF | ReportLab | Page layout, typography, embedded images |
| HTML | Jinja2 template | Self-contained HTML with inline CSS |
| Charts | matplotlib + networkx | Radar chart, knowledge graph, distribution bar |

Charts are rendered as PNG files in `{runtime}/wiki/report-assets/` and embedded in both PDF and HTML.

## Style Variants (future)

The `--style` flag selects a rendering template:

| Style | Audience | Tone |
|-------|----------|------|
| `demo` (default) | Public sharing, viral | Dark mode, gradient, impressive stats, bold insights |
| `editorial` | Professional/LinkedIn | White background, clean typography, polished |
| `minimal` | Personal reference | Simple document, focus on content over design |

Phase 1 implements `demo` only. Other styles are future additions using the same data pipeline with different templates.

## What Makes It Viral

1. **The one-paragraph synthesis** — "My AI wrote this about me after reading 1,035 documents" is the share-worthy moment
2. **Patterns & blind spots** — people want to know what their data reveals about them
3. **Work:life ratio** — personal and slightly provocative, invites conversation
4. **Knowledge graph** — visual proof of interconnected knowledge
5. **"Zero manual curation"** — the punchline. No one organized anything. The AI did it all.
6. **Portfolio images** — makes it personal and polished
7. **Augur branding** — every screenshot is free marketing
