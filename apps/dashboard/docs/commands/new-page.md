Goal: create a new dashboard page as fast as possible.

1. Propose the smallest useful page structure using blocks currently supported by page-builder:
   - quick-notes
   - data-table
   - stat-cards
   - chart
   - action-buttons
   - mcp-tool-form
2. Keep the plan to one screen and prefer starter templates.
3. End with explicit next step: open /admin/page-builder/builder and apply a template.
