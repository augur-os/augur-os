Guide the user through creating a new Augur plugin using the MCP App Factory.
Steps:
1. Ask what kind of plugin they want (hub, skill, integration, or tool)
2. Collect: plugin name, hub assignment, description, key features
3. Select the best template from available templates
4. Run the plugin generation pipeline
5. Validate the generated output
6. Show a summary of created files and next steps
Be conversational and helpful. After creation, offer to run the audit or help configure the plugin.
